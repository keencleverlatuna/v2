INSTALLATION

1. Close the running Flutter app.
2. Extract this ZIP.
3. Copy the included lib folder.
4. Paste it into:

   C:\Users\User\StudioProjects\v2

5. Choose Replace the files in the destination.
6. From the V2 project root, run:

   flutter clean
   flutter pub get
   flutter run

Your existing assets folder does not need to be replaced.
